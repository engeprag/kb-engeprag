## [1.0.0] - 2026-06-11

### Publicação
- Base de conhecimento pública sobre **controle de pragas urbanas**: artigos
  educativos, FAQ, descrição de serviços, glossário técnico, índice de conceitos
  e fontes/normas de referência.
- **Dados estruturados** (Schema.org/JSON-LD), `llms.txt`, `ai.txt`, `robots.txt`
  e índice estruturado (`kb_index.json`) para indexação e descoberta
  automatizada.
- Site publicado via **GitHub Pages** (MkDocs Material).

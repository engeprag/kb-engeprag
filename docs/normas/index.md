## Normas Federais (ANVISA)

### RDC 622/2021 - Empresas de Controle de Pragas

| Campo | Informação |
|-------|------------|
| **Órgão** | ANVISA |
| **Assunto** | Requisitos para funcionamento de empresas de controle de pragas |
| **Status** | Vigente |
| **Artigo** | [artigos/rdc-622.md](../artigos/rdc-622.md) |
| **Fonte Oficial** | [DOU](https://www.in.gov.br/web/dou/-/resolucao-rdc-n-622-de-9-de-marco-de-2022-383097904) |

**Resumo**: Estabelece requisitos sanitários mínimos para funcionamento de empresas especializadas em controle de vetores e pragas urbanas.

**Principais requisitos**:
- Responsável técnico habilitado
- Licença sanitária
- Registro de produtos utilizados
- Equipamentos de proteção
- Procedimentos documentados

## Normas Estaduais (São Paulo)

### Comunicado CVS 006 - Limpeza de Caixas d'Água

| Campo | Informação |
|-------|------------|
| **Órgão** | CVS-SP (Centro de Vigilância Sanitária) |
| **Assunto** | Periodicidade de limpeza de reservatórios |
| **Aplicação** | Estado de São Paulo |
| **Artigo** | [artigos/comunicado-cvs-006.md](../artigos/comunicado-cvs-006.md) |
| **Fonte Oficial** | [CVS-SP](https://www.cvs.saude.sp.gov.br) |

**Resumo**: Define a obrigatoriedade de limpeza semestral de caixas d'água e reservatórios.

**Estabelecimentos obrigados**:
- Comerciais
- Industriais
- Condomínios
- Instituições de saúde
- Escolas

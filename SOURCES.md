## Como Adicionar Novas Fontes

### Critérios de Aceitação

1. **Oficialidade**: Preferir fontes governamentais ou institucionais
2. **Atualidade**: Verificar data de publicação
3. **Acessibilidade**: Link deve estar ativo e acessível
4. **Relevância**: Relação direta com controle de pragas urbanas

### Processo

1. Identificar a fonte primária
2. Verificar credibilidade (órgão, autoria, data)
3. Adicionar entrada neste arquivo (SOURCES.md)
4. Atualizar o artigo com referência
5. Atualizar front-matter do artigo (campo `sources`)
